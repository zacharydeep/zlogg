# 测试与性能

- 优先扩展现有测试体系；修复缺陷必须增加可复现用例。
- 覆盖空文件、LF/CRLF、超长行、无末尾换行及 4 GiB 以上偏移。
- 覆盖 UTF-8/BOM、UTF-16 LE/BE、GBK/GB18030 和损坏编码。
- 覆盖追加/截断/替换、搜索取消、重复搜索、关闭标签及退出竞态。
- 大文件由脚本确定性生成，不提交入库；223 MB、1 GB、10 GB 测试按需运行。
- 性能对比使用相同环境与数据，记录硬件、构建配置及冷/热缓存条件。
- 分别测量首屏、完整索引、滚动、搜索、取消延迟，以及峰值 Private Bytes/Working Set。
- 性能阈值依据基线制定；不得把估算、稀疏文件测试或未执行测试当作实测结论。
